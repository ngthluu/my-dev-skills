# 0.1.10

Released: 2026-10-26

## Improvements

- Brainstorm session folders are now date-prefixed: `.my-dev-skills/yyyy-mm-dd-<slug>/`, so sessions sort by date.
- Brainstorm's decision ledger script is now `scripts/ledger.py`. It uses only the Python standard library and behaves as before.

## Upgrade notes

- The brainstorm ledger now runs with `python3` instead of `node`, so Python 3 must be available where the agent runs. Node.js is still needed for the `npx skills` installer.
- Brainstorm no longer creates browser visuals. The HTML templates, examples, and the optional `visuals/` folder have been removed; decisions and comparisons stay in chat.
- Pass the new date-prefixed spec path to implement, for example `Use the implement skill with .my-dev-skills/2026-10-26-activity-log/README.md.`
