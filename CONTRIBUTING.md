# Contributing

Anyone is welcome to open an [issue](https://github.com/ngthluu/my-dev-skills/issues) to report a bug or suggest a change. Please describe the problem, the behavior you expected, and any steps or examples that help reproduce it.

This project does not accept external pull requests. The maintainer implements changes and opens any pull requests needed for the project.

Maintainer changes should stay focused and include relevant verification. Edit each shared skill in its owning folder under `skills/` so its supporting files are installed with it. Before submitting a maintainer change, run `npm test`, `npm run validate`, and `git diff --check`. The [release guide](docs/releases.md) covers publication.
